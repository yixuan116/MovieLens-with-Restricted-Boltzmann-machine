Evaluation metric

Root Mean Squared Error

How far the model's predicted rating lands from what the user actually gave — averaged across every held-out test rating.

RMSE = 1 n ∑ i=1 n ( y^i − yi ) 2
n Test-set size — total held-out ratings scored (1,032,307 here) y⁢ᵢ Actual rating — what the user really gave that movie ŷ⁢ᵢ Predicted rating — what the model guessed
Worked example
row 1: actual 4.0 → predicted 3.5 → error² = 0.25
row 2: actual 5.0 → predicted 3.0 → error² = 4.00
...
average of all error² → square root
